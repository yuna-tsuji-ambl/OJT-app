# メッセージアナウンス テスト仕様書

## 概要

質問・メッセージ機能（F-03）の拡張として、過去メッセージの**ペア共有アナウンス**と、トーク一覧プレビュー／ブックマーク取得エラーの UI 微修正を対象とする。

**仕様の正**: 本仕様書の「確定事項」および [message-feature.md](./message-feature.md) / [message-timestamp-bookmark-feature.md](./message-timestamp-bookmark-feature.md)（本仕様で明示的に上書きする項目以外）。

### 確定事項

| #   | 論点             | 決定                                                                                             |
| --- | ---------------- | ------------------------------------------------------------------------------------------------ |
| 1   | 所有             | **ペア共有**（1 メッセージ最大 1 件。参加者双方が閲覧・解除可）                                  |
| 2   | 操作ロール       | **新卒・トレーナー双方**（自分／相手メッセージとも可）                                           |
| 3   | UI（トグル）     | 吹き出し横。ブックマーク ♥ とは**別トグル**                                                      |
| 4   | UI（導線）       | タイトル行のステータス横「アナウンスメッセージ〇件」。クリックで**右ペイン全体**を一覧に差し替え |
| 5   | 並び替え         | BM メッセージと同キー（送信時刻／アナウンス追加 × 昇降順）。一覧ヘッダー右                       |
| 6   | ロール絞り込み   | すべて／新卒アナウンスのみ／トレーナーアナウンスのみ（**アナウンスした人のロール**）             |
| 7   | 永続化・API      | Firestore `messageAnnouncements` ＋ `/api/message-announcements`                                 |
| 8   | トークプレビュー | 先頭メッセージは **1 行まで**（CSS line-clamp）                                                  |
| 9   | BM 取得エラー    | 「ブックマークを取得できませんでした」は**画面に出さない**（空扱い）。更新失敗アラートは維持可   |
| —   | 設計 ID / Issue  | F-03 / [#30](https://github.com/yuna-tsuji-ambl/OJT-app/issues/30)                               |

## 1. API（結合）

| テスト ID | 観点                 | 入力／操作                              | 期待結果                                   | 自動化 |
| --------- | -------------------- | --------------------------------------- | ------------------------------------------ | ------ |
| I-AN01    | 作成                 | 参加者が POST `{ threadId, messageId }` | 201。GET に出る。enrich 済み               | 自動   |
| I-AN02    | 幂等                 | 同一 messageId を再 POST                | 201。既存と同じ id。件数は増えない         | 自動   |
| I-AN03    | 共有一覧             | 新卒が作成 → トレーナーが GET           | 200。同じアナウンスが返る                  | 自動   |
| I-AN04    | 双方解除             | 相手が作成した件を DELETE               | 204。双方の GET から消える                 | 自動   |
| I-AN05    | 参加者外             | 非参加者が POST／GET／DELETE            | 403（DELETE は対象が参加者スレッドの場合） | 自動   |
| I-AN06    | 未認証               | ヘッダーなし GET                        | 401                                        | 自動   |
| I-AN07    | 存在しないメッセージ | 不正 messageId で POST                  | 404                                        | 自動   |
| I-AN08    | 共有メモ更新         | 参加者が PATCH `{ memo }`               | 200。双方の GET に同じ memo                | 自動   |
