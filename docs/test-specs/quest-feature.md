# クエスト（目標）管理機能 テスト仕様書

## 概要

スプレッドシートの育成計画（OJT計画書）と連動し、新卒がタスクのクリア申請を行い、OJTトレーナーが承認する機能。

OJTトレーナーはダッシュボード画面上部のクエスト作成機能から新しいクエストを追加できる。追加されたクエストは、トレーナー・新卒のどちらでログインしても一覧表示される。新卒はそのクエストに対してクリア申請ができ、トレーナーは申請状況を確認し、申請中のものを承認できる。申請済み・承認済みのクエストも、双方の一覧画面に表示される。
