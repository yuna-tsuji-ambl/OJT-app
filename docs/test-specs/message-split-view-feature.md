# メッセージ画面スプリットビュー改善 テスト仕様書

## 概要

質問・メッセージ機能（F-03）のうち、**トーク一覧／送信 UI／開いているトーク詳細の視認性・レイアウト**を改善する。  
現行はルーム選択時に一覧行の**直下へインライン展開**（[message-feature.md](./message-feature.md) R-M17）するが、本仕様では **左右分割（スプリットビュー）** に置き換える。あわせて、**テンプレートと自由記述の同時送信**、および **一覧末尾の空トーク表示の除去** を対象とする。

**仕様の正**: 本仕様書の「確定事項」および [message-feature.md](./message-feature.md)（本仕様で明示的に上書きする項目以外）。  
確認事項はすべて解消済み（末尾「確定ログ」参照）。実装（Red → Green）に進めてよい。

### 業務・UI ルール（確定）

| ルール ID | 内容                                                                                                                                                                                           |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| BR-SV01   | メッセージ画面は **左ペイン（送信 UI ＋ トーク一覧）／右ペイン（選択中トーク詳細）** の 2 カラムとする。**画面幅にかかわらず左右スプリット固定**（狭い画面でもスタックや下展開に切り替えない） |
| BR-SV02   | トーク行クリックで詳細を右ペインに表示する（R-M17 の直下インライン展開は採用しない）                                                                                                           |
| BR-SV03   | 選択中行のスタイル: 背景 `rgba(59, 108, 237, 0.20)`、左ボーダー `3px solid var(--primary)`（`--primary: #3b6ced`）                                                                             |
| BR-SV04   | テンプレートと自由記述を両方指定して送信した場合、**同一 `threadId` に 2 通**（1 通目: テンプレ文、2 通目: 自由記述）。新卒の新規質問・トレーナー返信の双方に適用                              |
| BR-SV05   | トーク一覧の**最下部に出る、実トーク行と同系色だが中身のないボックス（UI ゴースト）**を表示しない                                                                                              |
| BR-SV06   | テンプレ選択あり＋自由記述が空白のみのときは **テンプレのみ送信**する（空白自由記述は送らない）                                                                                                |
| BR-SV07   | トークが 1 件以上あるとき、初期表示および一覧更新後に **最新トーク（一覧先頭＝新しい順の先頭）を自動選択**し、右ペインにその詳細を出す                                                         |
| BR-SV08   | トークが 0 件のとき、右ペインに **「メッセージを送信してください」** を表示する（履歴・返信入力は出さない）                                                                                    |
| BR-SV09   | 選択中ルームの **再クリックでは選択を解除しない**（右ペインは開いたまま、選択状態を維持）                                                                                                      |
| BR-SV10   | 本機能の自動化対象テストが CI で Pass する                                                                                                                                                     |

### 親仕様からの上書き

| 親仕様                                           | 本仕様での扱い                                   |
| ------------------------------------------------ | ------------------------------------------------ |
| R-M17（選択行の DOM 直後に下方向インライン展開） | **廃止（本画面では適用しない）**。詳細は右ペイン |
| R-M17（同一ルーム再クリックで閉じる）            | **廃止**。再クリックでも選択維持（BR-SV09）      |
| 選択状態の色分け                                 | BR-SV03 の具体色を必須化                         |
| U-M01 / U-M02（テンプレのみ／自由記述のみ）      | 単独送信は継続。**両方同時は 2 通**（本仕様）    |

スタンプ・LINE 風吹き出し・新しい順・リアルタイム等、上表に無い項目は [message-feature.md](./message-feature.md) を正とする。

### レイアウト（目標）

```
+---------------------------+------------------------------+
| 左ペイン                  | 右ペイン                     |
| - 送信（テンプレ/自由記述 | - 最新トーク自動選択時:      |
|   /スタンプ等）           |   履歴・返信入力             |
| - トーク一覧              | - トーク 0 件時:             |
|   （選択行: 濃色＋左線）  |   「メッセージを送信してください」 |
+---------------------------+------------------------------+
※ 画面幅によらずこの左右固定
```
