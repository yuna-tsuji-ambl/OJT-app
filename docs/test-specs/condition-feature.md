# モヤモヤ・温度計機能 テスト仕様書

## 概要

新卒が週次で自身のコンディション（業務量、理解度、メンタル）を入力し、トレーナーがそれを把握・アラート検知する機能。

### UI仕様（表示・導線）

| 項目                     | 仕様                                                                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| 新卒の入力ステート       | 新卒が入力した業務量・理解度・メンタルは送信後に永続化され、再取得時に同じ値が確認できること                         |
| トレーナーヘッダー       | トレーナー画面のヘッダーに「コンディション」ナビゲーションを追加する                                                 |
| トレーナーのステート確認 | トレーナーはコンディション画面の画面上部で、対象新卒の現在のコンディション（業務量・理解度・メンタル）を確認できる   |
| コンディション推移グラフ | 現在のコンディション表示の直下に配置する。コンディションが変更（再入力）されるたびに、最新データを反映して更新される |
| 入力値バリデーション     | 業務量・理解度・メンタルはいずれも 1〜5 の整数のみ許可する（ドメイン層で検証し、不正値は API が 400 を返す）         |
