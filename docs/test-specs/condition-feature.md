# モヤモヤ・温度計機能 テスト仕様書

## 概要

新卒が週次で自身のコンディション（業務量、理解度、メンタル）を入力し、トレーナーがそれを把握・アラート検知する機能。

### UI仕様（表示・導線）

| 項目                                   | 仕様                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 新卒の入力ステート                     | 新卒が入力した業務量・理解度・メンタルは送信後に永続化され、再取得時に同じ値が確認できること                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| トレーナーヘッダー                     | トレーナー画面のヘッダーに「コンディション」ナビゲーションを追加する                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| トレーナーのステート確認               | トレーナーはコンディション画面の画面上部で、対象新卒の現在のコンディション（業務量・理解度・メンタル）を確認できる                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| トレーナーコンディション画面のアラート | 対象新卒の現在のメンタルが「1」の場合、トレーナーのコンディション画面にアラート「新卒のメンタルが不安定です。」を表示する                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| コンディション推移グラフ               | 現在のコンディション表示の直下に、コンディションステートの推移を**折れ線グラフ**で表示する。業務量・理解度・メンタルの 3 系列を折れ線で表示し、コンディションが変更（再入力）されるたびに最新データを反映して更新する。軸・目盛の詳細は下記「折れ線グラフの軸・目盛」に従う。推移の数値一覧は下記「コンディション推移表」に従う                                                                                                                                                                                                                                              |
| 折れ線グラフの軸・目盛                 | 折れ線グラフは、[総務省統計局「なるほど！統計」折れ線グラフ](https://www.stat.go.jp/naruhodo/4_graph/shokyu/oresen-graph.html) と同様の見え方とする。**縦軸**に目盛 `1`・`2`・`3`・`4`・`5` を表示し、各目盛に対応する**横方向の補助線（グリッド）**を引く。**横軸**に各記録の**日付**を表示し、各日付に対応する**縦方向の補助線（グリッド）**を引く。3 系列の折れ線はこの座標系上にプロットする。折れ線グラフの直下に、スケール範囲のテキスト（例: `1〜5`）、記録日時の箇条書き（例: `2026-07-08` の繰り返し）、系列ごとの数値リスト（例: `3, 3` / `1, 1`）を**表示しない** |
| コンディション推移表                   | 折れ線グラフの直下に、コンディション記録の推移を**表形式**で表示する。列は **記録日時**・**業務量**・**理解度**・**メンタル** とし、各行は 1 回の記録に対応する。記録が複数ある場合は記録日時の昇順（古い順）で行を並べる。同一日付の再入力がある場合も、それぞれを別行として表示する（表示例は下記）。コンディションが再入力されるたびに、最新データを反映して更新する。表の見た目・構造の詳細は下記「コンディション推移表（L字マトリクス）」および「コンディション推移表（罫線付きグリッド）」に従う                                                                       |
| 入力値バリデーション                   | 業務量・理解度・メンタルはいずれも 1〜5 の整数のみ許可する（ドメイン層で検証し、不正値は API が 400 を返す）                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

### 追加UI仕様（コンディション推移グラフ・推移表の改善）

| 項目                                     | 仕様                                                                                                                                                                                                                                                                                                                                              |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 折れ線グラフの表示サイズ                 | 折れ線グラフの描画領域は、**現状より大きめ**に表示する。縦軸目盛（`1`〜`5`）・プロット領域・横軸の日付ラベルが、十分な余白をもって読み取れること                                                                                                                                                                                                  |
| 折れ線グラフの横スクロール               | 記録件数が多く画面幅に収まらない場合、折れ線グラフ**内**を横方向にスクロール（またはスワイプ）でき、画面外の記録日時・データ点・縦方向グリッド線も閲覧できること。縦軸目盛はスクロール時も見える位置に固定表示すること                                                                                                                            |
| 折れ線グラフの横軸位置揃え               | 各記録の横軸日付ラベルの**横位置**（中心または下端の対応点）が、その記録のデータ点および縦方向グリッド線の **x 座標と一致**すること。同一日付の記録が複数ある場合は、各記録ごとに個別の位置へ表示すること（日付ラベルの重なりや、点とラベルのずれを許容しない）                                                                                   |
| 折れ線グラフの横軸ラベルの縦位置揃え     | 各記録の横軸日付ラベルの**縦位置**が、プロット領域下端の**横軸基準線の高さ（y 座標）**に揃うこと。すべての日付ラベルが横軸上に一直線に並び、ラベルの基準点（下端）が横軸基準線と一致すること（ラベルがプロット領域内に食い込んだり、基準線から離れて浮いて見えないこと）                                                                          |
| コンディション推移表（L字マトリクス）    | 推移表は `<table>` による **L 字型マトリクス**として表示する。1 行目に列見出し（記録日時・業務量・理解度・メンタル）、2 行目以降にデータ行を配置し、見出し行とデータ行が表構造として視覚的に区別できること（単なるテキストの縦並びではないこと）。列見出しは `columnheader`、データセルは `cell` としてアクセシビリティ上も表として認識できること |
| コンディション推移表（罫線付きグリッド） | 記録日時・業務量・理解度・メンタルを表示する各セルが、**罫線（ボーダー）で区切られたグリッド表**として表示されること。列見出しセル・データセルのそれぞれが上下左右の境界線により個別に識別でき、行・列の区切りが視覚的に明確であること（罫線のないテキスト並びは不可）                                                                            |

**現状の課題（改善前の表示例）**

折れ線グラフの横軸日付とプロット点の x 位置がずれ、同一日付ラベルが重複表示される場合がある。横軸日付ラベルの縦位置が横軸基準線からずれる場合がある。推移表は列見出しと値が表として十分に区別されない場合がある。推移表のセル間に罫線がなく、値の区切りが視覚的に不明瞭な場合がある。

```
1
2
3
4
5
2026-07-14
2026-07-14
2026-07-14
2026-07-14
記録日時  業務量  理解度  メンタル
2026-07-14  3  3  3
2026-07-14  4  3  3
2026-07-14  4  3  1
2026-07-14  4  2  1
```

**推移表の表示例（L字マトリクス・罫線付きグリッド）**

| 記録日時   | 業務量 | 理解度 | メンタル |
| ---------- | ------ | ------ | -------- |
| 2026-07-13 | 4      | 3      | 3        |
| 2026-07-13 | 4      | 3      | 1        |

※ 実際の画面では、上記の各セル（見出し・データ）が罫線で区切られて表示されること。
