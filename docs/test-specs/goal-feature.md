# 目標・ガントチャート管理機能 テスト仕様書

## 概要

OJT 期間中の**期間付き目標（タスク）**を登録し、**ガントチャート**でスケジュール・進捗を可視化する機能。  
ヘッダー「目標」から到達し、**新卒・トレーナー双方が作成・変更でき、同一データとして連動**する。ガント上のバー移動・期間変更操作を初版スコープに含む。

**仕様の正**: 本仕様書の「確定事項」および `docs/detailed-design.md` §7.6、§6.1、§8.6.3、§9（`goals` コレクション）  
※詳細設計と本仕様の差分は「確定事項」を優先し、実装時に詳細設計へ同期する。

### 確定事項（レビュー回答）

| #   | 論点                                     | 決定                                                                                               |
| --- | ---------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 1   | ガントのドラッグ移動・端ドラッグ期間変更 | **初版スコープに含める**（詳細設計の「Phase 2」表記より本決定を優先）                              |
| 2   | 作成・変更の権限                         | **新卒も作成可能**。**トレーナーも作成・変更可能**。双方の操作は**同一 Goal データとして連動**する |
| 3   | `/goals/manage` のロール                 | **新卒・トレーナー双方が利用可能**（作成・変更）。画面差は小さく、権限差は主に削除                 |
| 4   | 削除権限                                 | **トレーナーのみ**。新卒は削除不可（API・UI とも）                                                 |
| 5   | 同一日目標（`startDate === endDate`）    | **許可する**（U-G20: HTTP 200/201）                                                                |
| 6   | `title` / `description` 最大文字数       | **title: 100 文字**、**description: 1000 文字**（U-G21/U-G22）                                     |
| 7   | 進捗とステータスの連動                   | **自動連動なし**（`progress=100` でも `status` は自動 `completed` にしない）                       |
| 8   | 作成直後の初期値                         | **`progress=0`**、**`status=not_started`**                                                         |
| 9   | `GET /api/goals` の `traineeId` 省略時   | **新卒: 自身の目標**。**トレーナー: 担当新卒（`trainee-1`）をデフォルト**                          |
| 10  | 担当外アクセス時（トレーナー一覧）       | **HTTP 403**（U-G15）                                                                              |
| 11  | バー移動時の日付更新規則                 | **期間長（日数）を維持**して `startDate`/`endDate` をシフト                                        |
| 12  | 端ドラッグの対象端                       | **左端＝開始日変更**、**右端＝終了日変更**                                                         |

### 画面・導線

| 項目               | 内容                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| ヘッダー文言       | 新卒・トレーナーとも「目標」                                                                      |
| ガントチャート画面 | `/goals`（新卒・トレーナー）。期間横軸 + タスクバーでスケジュール・進捗を表示                     |
| 管理画面           | `/goals/manage`（新卒・トレーナー）。登録・変更は双方。**削除操作はトレーナーのみ表示・実行可**   |
| ガント操作         | バー本体を左クリック＋スライドで位置移動。端を左クリック＋スライドで期間（開始/終了）変更（初版） |
| 連動               | 新卒・トレーナーのどちらかが作成・変更した内容を、もう一方でも同じ目標として確認・操作できる      |
| ロール差の要約     | 作成・変更・閲覧・ガント操作は双方。**削除だけトレーナー**                                        |

### 入力項目定義（§7.6.4 ドメインモデル）

| 内部キー          | 画面表示名（想定） | 型 / 制約（設計書記載）                                      |
| ----------------- | ------------------ | ------------------------------------------------------------ |
| `title`           | 目標名             | string（必須想定）                                           |
| `description`     | 説明               | string（任意）                                               |
| `traineeId`       | 担当新卒           | string                                                       |
| `startDate`       | 開始日             | ISO 8601 date（`YYYY-MM-DD`）                                |
| `endDate`         | 終了日             | ISO 8601 date（`YYYY-MM-DD`）                                |
| `progress`        | 進捗率             | number（0〜100）                                             |
| `status`          | ステータス         | `'not_started' \| 'in_progress' \| 'completed' \| 'blocked'` |
| `dependsOnGoalId` | 依存目標           | string（任意。詳細設計では Phase 2）                         |

### 業務ルール（詳細設計・依頼仕様）

| ルール ID | 内容                                                                                                         |
| --------- | ------------------------------------------------------------------------------------------------------------ |
| BR-G01    | 目標は期間（`startDate` / `endDate`）付きで登録し、ガントチャートにバーとして表示する（UC-G01）              |
| BR-G02    | 進捗率（0〜100%）およびステータスを更新でき、ガント表示に反映される（UC-G02）                                |
| BR-G03    | 新卒・トレーナーは `/goals` でガントチャートを閲覧できる（UC-G03）                                           |
| BR-G04    | Goal の永続化先は Firestore `goals` コレクションとする                                                       |
| BR-G05    | API は Goal CRUD を提供する。`POST`/`PUT` は新卒・トレーナー双方。`DELETE` はトレーナーのみ（確定事項 2・4） |
| BR-G06    | ヘッダーに「目標」項目を設け、当該機能へ遷移できる                                                           |
| BR-G07    | 新卒・トレーナーのどちらかが作成・変更した内容は、もう一方でも同一目標として確認・操作できる（連動）         |
| BR-G08    | ガントバーを左クリック＋スライドで位置移動できる（初版）                                                     |
| BR-G09    | ガントバー端を左クリック＋スライドで期間変更できる（初版）                                                   |
| BR-G10    | 本機能の自動化対象テストが CI で Pass する                                                                   |
| BR-G11    | `/goals/manage` は新卒・トレーナー双方が利用できる。削除 UI はトレーナーのみ（確定事項 3・4）                |

### API エンドポイント（本仕様・確定事項反映）

| メソッド | パス             | ロール（本仕様） | 説明                               |
| -------- | ---------------- | ---------------- | ---------------------------------- |
| GET      | `/api/goals`     | trainee, trainer | ガント用目標一覧（`?traineeId=`）  |
| POST     | `/api/goals`     | trainee, trainer | 目標作成（双方。連動）             |
| PUT      | `/api/goals/:id` | trainee, trainer | 目標更新（タイトル・期間・進捗等） |
| DELETE   | `/api/goals/:id` | trainer          | 目標削除（新卒は 403）             |

※詳細設計 §8.6.3 の `POST` trainer のみ表記は、本仕様の確定事項を優先し詳細設計を後続で同期する。
