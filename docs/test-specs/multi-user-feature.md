# 複数新卒・複数トレーナー対応 テスト仕様書

## 概要

現行は `trainee-1` / `trainer-1` の**固定 1 対 1**。複数の新卒・複数のトレーナーを扱えるよう、**ユーザー／担当関係のデータモデル**、**認証連携（F-10）との整合**、および**各機能に散在する固定ユーザー ID の除去**を行う機能（F-11）。

**仕様の正**: 本仕様書の「確定事項」および `docs/detailed-design.md` §5、§13（#3）、関連機能の認可仕様  
※詳細設計上のステータスは **計画のみ**。確定事項以外は末尾「※残確認事項」。F-10 先行のため、F-11 の本実装は F-10 の ID 供給と矛盾しない形で進める。
