# メッセージ送信時刻表示・ブックマーク テスト仕様書

## 概要

質問・メッセージ機能（F-03）の拡張として、次の 2 点を対象とする。

1. **送信時刻の可視化** — 各メッセージ（および必要ならトーク一覧）から「いつ送られたか」が分かるようにする
2. **ブックマーク** — **トーク（ルーム）** と **メッセージ（個別）** それぞれをお気に入りとして保存・参照できるようにする

**仕様の正**: 本仕様書の「確定事項」および [message-feature.md](./message-feature.md) / [message-split-view-feature.md](./message-split-view-feature.md)（本仕様で明示的に上書きする項目以外）。  
送信時刻・ブックマークの確認事項は **解消済み**（用語 BM＝ブックマーク）。送信時刻の文言／TZ のみ暫定運用。

## 1. 送信時刻の表示（**採用: T-C**）

> 親仕様では **トーク一覧行** に最終やり取り日時がある。本拡張は **右ペインの個別メッセージ** に日付区切り＋時刻を付ける。

### 案比較（参考・T-C 採用済み）

| 案 ID | 名称                     | 概要                                                                                       | 採否     |
| ----- | ------------------------ | ------------------------------------------------------------------------------------------ | -------- |
| T-A   | 各吹き出しに絶対時刻     | 各メッセージ近傍に `YYYY年M月D日 H:mm`（ローカル）を常時表示                               | 不採用   |
| T-B   | 相対時刻＋絶対の補完     | 既定表示は「○分前」等。ホバー等で絶対時刻                                                  | 不採用   |
| T-C   | 日付区切り＋時刻のみ     | 履歴内に日付セパレータ。各吹き出しは `H:mm` のみ。**メッセージが無い日の区切りは出さない** | **採用** |
| T-D   | 折りたたみ（詳細で表示） | 既定は時刻非表示。操作で `createdAt` を表示                                                | 不採用   |

### 案ごとの表示例（イメージ）

**T-A（絶対時刻）**

```
[トレーナー] 了解です          2026年7月29日 14:30
              あなた] ありがとうございます  2026年7月29日 14:32
```

**T-B（相対＋絶対）**

```
[トレーナー] 了解です          2分前   ← title/aria に絶対時刻
```

**T-C（日付区切り＋時刻）— 採用**

```
──────── 2026年7月29日 ────────
[トレーナー] 了解です          14:30
              あなた] ありがとうございます  14:32
──────── 今日 ────────
[トレーナー] 確認しました      09:05
```

> **空日の区切りは出さない例**: 7/29 と「今日」（例: 8/3）にだけメッセージがあり、7/30〜8/2 に送信が無い場合、その間の日付区切り（7/30・7/31…）は **当該トーク欄に一切出さない**。

### 既存データとの関係（事実）

| 項目                       | 現状（親仕様・詳細設計）                                    |
| -------------------------- | ----------------------------------------------------------- |
| メッセージの時刻フィールド | `ThreadChatMessage.createdAt`（ISO 8601 文字列想定）        |
| トーク一覧の日時           | `MessageThread.updatedAt` → `YYYY年M月D日 H:mm`（ローカル） |
| 右ペイン履歴での時刻表示   | **T-C で実装する（確定）**                                  |

### 送信時刻まわりの業務ルール

| ルール ID | 内容                                                                                                                                  | 状態     |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| BR-TB01   | 右ペイン履歴は **T-C**: 日付が変わるタイミングで日付区切りを出し、各吹き出し近傍に **`H:mm`**（ローカル）を表示する                   | **確定** |
| BR-TB02   | 表示に用いる値は永続化された `createdAt` とし、クライアントローカル TZ で日付境界・時刻を判定・整形する                               | 案       |
| BR-TB03   | 機械可読のため吹き出し側の時刻は `time` 要素の `datetime`（ISO 8601）または同等属性を付与する                                         | 案       |
| BR-TB04   | スタンプ・テンプレート・自由記述のいずれも同一ルール（区切り＋`H:mm`）を適用する                                                      | **確定** |
| BR-TB05   | トーク一覧の最終やり取り日時表示は親仕様を維持する（本拡張で壊さない）                                                                | **確定** |
| BR-TB06   | 日付区切りは **当該トークの履歴にメッセージが 1 通以上あるローカル日付にだけ**出す。メッセージが無い日の区切りは **作成・表示しない** | **確定** |
| BR-TB07   | 同一ローカル日付に複数通ある場合、日付区切りは **その日の先頭メッセージの直前に 1 回だけ**出す（通ごとには繰り返さない）              | **確定** |

## 2. ブックマーク機能

> **用語**: 本仕様の **BM = ブックマーク**（Bookmark）の略。

### 対象の区別

| 対象                   | 意味                                                            |
| ---------------------- | --------------------------------------------------------------- |
| トークブックマーク     | `MessageThread`（ルーム）単位。一覧から素早く辿れるようにする   |
| メッセージブックマーク | `ThreadChatMessage`（個別吹き出し）単位。特定発言を後で参照する |

### 想定ユースケース

| UC ID   | 主体              | 操作                                            | 結果                                 |
| ------- | ----------------- | ----------------------------------------------- | ------------------------------------ |
| UC-BM01 | 新卒 / トレーナー | トーク行でブックマーク ON/OFF                   | 自分のブックマーク状態が永続化される |
| UC-BM02 | 新卒 / トレーナー | 吹き出し（自分・相手とも）でブックマーク ON/OFF | 自分のブックマーク状態が永続化される |
| UC-BM03 | 同上              | ブックマーク済みトークのみ一覧フィルタ          | 該当トークのみ表示                   |
| UC-BM04 | 同上              | ブックマーク済みメッセージ一覧を開く            | 紐づくトークへ遷移できる             |

### UI 配置（確定: (A)+(B)+(C)）

```
+---------------------------+------------------------------+
| 左ペイン                  | 右ペイン                     |
| [★フィルタ: BMトークのみ] | [BMメッセージ一覧を開く]     |  ← (C) 初版に含む
|                           |                              |
| トーク行                  |  ──────── 今日 ────────      |
|  ★ プレビュー…  日時     |  [相手] 本文…     ★  14:30  |  ← (B)
|  ★ プレビュー…  日時     |  [あなた] 本文…   ★  14:32  |
|     ↑ (A)                 |                              |
+---------------------------+------------------------------+
```

| 配置 ID | 場所                                      | 初版 |
| ------- | ----------------------------------------- | ---- |
| (A)     | 左: トーク一覧の各行の ★                  | ○    |
| (B)     | 右: 各吹き出し近傍の ★                    | ○    |
| (C)     | BM トークフィルタ＋ BM メッセージ一覧導線 | ○    |

### ドメインモデル（目標・おすすめ確定）

```typescript
/** ユーザー単位のブックマーク。Firestore: messageBookmarks */
interface MessageBookmark {
  id: string; // 推奨: `${ownerUserId}_${targetType}_${threadId}` または message 時は messageId を含める
  ownerUserId: string;
  targetType: 'thread' | 'message';
  threadId: string;
  messageId?: string; // targetType === 'message' のとき必須
  createdAt: string;
}
```

### ブックマークの業務ルール

| ルール ID | 内容                                                                          | 状態     |
| --------- | ----------------------------------------------------------------------------- | -------- |
| BR-BM01   | トークとメッセージは **別ターゲット** としてブックマークできる                | **確定** |
| BR-BM02   | ブックマークの所有は **操作したユーザー個人**（相手には見えない）             | **確定** |
| BR-BM03   | 同一ユーザー・同一ターゲットの二重登録はしない（トグル OFF で解除）           | **確定** |
| BR-BM04   | 自分が参加していないトーク / 見えないメッセージはブックマーク不可（403 等）   | **確定** |
| BR-BM05   | トーク／メッセージ **本体削除時はカスケードでブックマークも削除**する         | **確定** |
| BR-BM06   | 新卒・トレーナー双方が利用できる                                              | **確定** |
| BR-BM07   | UI は (A)(B)(C): トーク行 ★・吹き出し ★・BM トークフィルタ・BM メッセージ一覧 | **確定** |
| BR-BM08   | 本機能の自動化対象テストが CI で Pass する                                    | **確定** |
| BR-BM09   | ブックマーク件数に **上限なし**                                               | **確定** |
| BR-BM10   | メッセージ BM は **自分・相手どちらの吹き出しにも**付与できる                 | **確定** |

### API・永続化（おすすめ・確定 #9）

| メソッド | パス                         | ロール            | 説明                                         |
| -------- | ---------------------------- | ----------------- | -------------------------------------------- |
| GET      | `/api/message-bookmarks`     | trainee / trainer | 自分の一覧。`?targetType=thread\|message` 可 |
| POST     | `/api/message-bookmarks`     | trainee / trainer | 追加（幂等可）                               |
| DELETE   | `/api/message-bookmarks/:id` | trainee / trainer | 解除（所有者のみ）                           |

**POST ボディ例**:

```json
{ "targetType": "thread", "threadId": "…" }
```

```json
{ "targetType": "message", "threadId": "…", "messageId": "…" }
```

**永続化**: Firestore コレクション `messageBookmarks`。ドキュメント ID は所有者＋ターゲットで一意にし、二重登録を防ぐ。  
一覧 API（スレッド／履歴）への `bookmarked: boolean` 付与は **任意の最適化**（初版は専用 API のみでも可）。
