# 信頼性・タイムアウト・接続

## 目的

外部 I/O の無限待ちと接続枯渇を防ぐ。

## 既定値（初版案 ※レビューで確定）

| 項目                        | 既定案                                                   |
| --------------------------- | -------------------------------------------------------- |
| HTTP サーバ受信タイムアウト | プラットフォーム既定 / 明示する場合は 30s 目安           |
| Firestore 操作タイムアウト  | クライアント／ラッパで 10s 目安（未設定なら追従課題）    |
| 外部 HTTP 呼び出し          | 5–10s、リトライは冪等時のみ最大 2 回                     |
| 接続数                      | Firestore は SDK 管理。自前プールを持つ場合は env で上限 |

## 実装ルール

- タイムアウト値は定数または env（例: `FIRESTORE_TIMEOUT_MS`）
- マジックナンバー散在禁止
- 失敗時はドメイン／HTTP エラーへ変換し、握りつぶさない
