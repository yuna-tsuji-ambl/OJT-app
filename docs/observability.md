# 可観測性（ログ / OpenTelemetry）

## 現状

- OpenTelemetry: **未導入**（SDK・計装コードは本ドキュメントの方針のみ。実装は別 Issue）
- ログ: 起動・致命的エラーは `console` 中心（将来は構造化ログへ）

## ログ方針（現時点）

必須に近い情報（可能な範囲で）:

- 時刻、レベル、イベント名
- request 相関 ID（導入時）
- ユーザは内部 ID のみ（PII 最小化）

禁止:

- トークン、パスワード、Authorization ヘッダ
- 報告書本文・メッセージ本文などの機微データ

## OpenTelemetry（導入時方針）

| 項目         | 方針                                                 |
| ------------ | ---------------------------------------------------- |
| 計装箇所     | HTTP 入口、主要ユースケース、リポジトリ I/O          |
| 属性         | `http.method`, `http.route`, `user.role`（PII なし） |
| エクスポータ | 別途決定（Cloud Trace 等）                           |
| メトリクス   | request latency、5xx 件数                            |

導入は Issue 化し、依存追加はレビュー必須。本フェーズでは **方針ドキュメントと rules のみ**とし、計装実装は行わない。
